# Linux-Mint-Custom-Install
A custom installer for Linux mint that provides additional features to the OS

Окрім файлів коду та яриків для них код містить вставноленні за замовчуванням apt пакунки:
anydesk
rustdesk
copyq
xdotool
steam
cava
cmatrix
btop
htop
zram

Потім код встановлює flatpak програми під час 2 етапу інсталяції

Також додаються кастомні сполучення клавіш, яких немає в Linux Mint:
Super+L - Заблокувати систему
Super+H - Згорнути активне вікно
Super+V - Відкрити історію буфера обміну
Ctrl+Shift+Esc - Відкрити монітвр ресурсів
Ctrl+Alt+PgDn - Аварійне закриття програми

Повний список того, що додає в систему інсталлер:
Ставить автоматично драйвери nvidia(якщо вони потрібні) та підбирає версію драйвера
Ставить за замовчуванням цілу купу програм(apt програми по типу steam та anydesk вшиті в iso образ, а після встановлення на диск інсталюються flatpak програми)
Фіксить деякі дрібні баги Cinnamon та Bottles які можуть не сподобатись новачку
Автоматично створює Swap(Zram)
Додає цілий список сполучень клавіш, які новачки самі просили мене додати
Додає історію буфера обміну
Додає автоматичне монтування дисків при запуску(його можна легко вимкнути за потреби в автозавантаженні)

Після системи яка встановлена цим інсталлером можна одразу без жодних налаштувань завантажувати програми і грати в ігри.
